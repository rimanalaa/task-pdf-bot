# بوت PDF لحل التاسك

## التشغيل
1. بتيليجرام افتحي **@BotFather** ← `/newbot` ← اختاري اسم ويوزر للبوت ← انسخي الـ token.
2. افتحي ملف `.env` وحطي: `BOT_TOKEN=التوكن_هون`
3. دبل كليك على `run.bat` (لازم الشباك يضل مفتوح والبوت شغال).

## شو بيعمل البوت
`/start` ← لحد 3 لوجوهات ← الاسم ← الـ ID ← اسم الدكتور ← السنة ← إطار للصفحات أو بدون ← صور الحل بالترتيب ← «✅ اعمل الـ PDF».
كل الخطوات اختيارية (زر «تخطي») ما عدا الصور.
- الغلاف: اللوجوهات بالنص فوق (الأول على اليمين)، العنوان، الاسم/الرقم/الدكتور، والسنة آخر الصفحة.
- كل صورة بصفحة A4 مع الاسم والرقم (إذا موجودين) ورقم الصفحة، ومع إطار ذهبي إذا اختاره.
- بيتذكر بيانات كل مستخدم للمرة الجاية («نفس بياناتي»). «↩️ احذف آخر صورة» و `/cancel` موجودين.
- صورة البروفايل والوصف: `assets/avatar.png` و `set_profile.py`.
